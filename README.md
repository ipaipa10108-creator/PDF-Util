# Local PDF Web Suite（純本地端網頁 PDF 綜合處理工具）

![GitHub Workflow Status](https://img.shields.io/github/actions/workflow/status/ipaipa10108-creator/PDF-Util/deploy.yml?branch=main&label=Deploy%20Status&style=flat-square)
![License](https://img.shields.io/badge/license-MIT-blue?style=flat-square)
![Privacy](https://img.shields.io/badge/Privacy-100%25%20Local-emerald?style=flat-square)

一個現代化、高質感的網頁端 PDF 綜合編輯與電子簽署工具。

### 🔒 絕對的隱私與安全承諾

本工具為 **100% 靜態前端網頁應用**。所有的 PDF 解析、渲染、頁面編輯、裁切、簽章生成與加解密，皆在您的瀏覽器本地沙盒中完成。**100% 承諾不將任何文件、個資或簽名圖像上傳至任何後端伺服器**，保障極致的文件隱私安全。

---

## ✨ 核心功能

### 1. 📂 文件載入與預覽
支援拖放（Drag & Drop）或點擊上傳 PDF，即時以網格縮圖（Thumbnail Grid）形式渲染並呈現所有頁面與頁碼。

### 2. 🔐 密碼保護與自動破解 PDF 支援
- **開啟加密文件**：載入受密碼保護的 PDF 時，自動偵測並彈出精美的密碼輸入視窗，輸入正確密碼後即可正常讀取與編輯。
- **密碼錯誤提示**：密碼輸入錯誤時，顯示錯誤提示並保持彈窗開啟，可重新輸入，不強制關閉。
- **⚡ 自動密碼破解**：忘記密碼時可一鍵啟動本地破解功能，支援：
  - **字典攻擊**：內建 ~250 組常見密碼（包含數字組合、常用英文詞彙、台灣常用組合與年份）
  - **數字窮舉**：支援 4 位數（0000–9999）、5 位數與 6 位數純數字高速碰撞
  - **即時進度與速度**：視覺化進度條、當前嘗試密碼、每秒測試次數（次/秒），可隨時中途停止
  - **一鍵解鎖**：找到密碼後可直接複製或一鍵開啟文件
- **匯出密碼設定**：點擊「匯出」或「分享」時，彈出密碼選項對話框，提供三種模式：
  - **保留原始密碼**：輸出的 PDF 沿用來源文件的開啟密碼（僅當來源有密碼時顯示）
  - **設定新密碼**：為匯出的 PDF 設定一組全新密碼（含兩次確認輸入）
  - **解除密碼保護**：移除密碼，匯出的 PDF 可直接開啟

### 3. 🔄 頁面旋轉
支援單獨或批次勾選頁面進行順時針 90°、180°、逆時針 90° 旋轉，前端 UI 即時以動畫響應。

### 4. ❌ 頁面刪除與還原
一鍵標記刪除指定頁面，在 UI 上置灰顯示（可手動復原），並在最終導出時完全剔除。

### 5. ✂️ 頁面裁切（CropBox）
點擊每頁縮圖下方的「裁切」按鈕，可在互動式裁切框中精準選取保留區域，並可選擇「套用至全部頁面」。裁切資訊在最終 PDF 匯出時以標準 CropBox 寫入。

### 6. ➕ 插入外部 PDF 頁面
- **操作方式**：點擊頂部工具列（或手機底部懸浮列）的「**插入頁面**」按鈕，即可開啟插入彈窗。
- **自訂範圍**：可選擇插入全部頁面，或使用語法輸入框輸入自定義頁碼（如 `1, 3-5`，代表載入該 PDF 的第 1 頁與第 3 到第 5 頁，若語法錯誤將會出現紅字提示）。
- **視窗拖放插入**：已載入主文件時，可直接將第二個 PDF 拖放至瀏覽器視窗，自動彈出磨砂玻璃覆蓋層，放開後直接開啟插頁 Modal。
- **視覺化勾選頁面**：選擇「指定部分頁面」時，可核取「讀入插入 PDF 畫面」，系統自動渲染縮圖供直觀勾選。
- **定位插入**：可指定插入至主文件「最前面」或「第 N 頁之後」。
- **防偏移對齊**：所有已放置的電子簽章皆綁定唯一 `pageId`，即使插頁使頁面順序重排，簽章仍精準留在原頁面。

### 7. 🔀 頁面順序重排與指定位置移動
- **滑鼠拖曳排序**：直接拖動縮圖任意重排 PDF 頁面順序，拖放時虛線高亮提示放置點（電子簽章放置模式下自動禁用拖曳）。
- **指定位置移動**：每頁縮圖下方的「移動」按鈕，可輸入目標頁碼將該頁精準移至指定位置（輸入 `0` 代表移至最前面）。

### 8. 📐 指定頁面導出
自由勾選特定頁面重新打包，瀏覽器本地合成並下載全新的 PDF 檔案。

### 9. 🗜️ PDF 壓縮輸出

- 頂部工具列提供「壓縮比例」Slider，可在下載或分享前調整輸出品質與檔案大小。
- `100%` 會優先保留原始 PDF 向量內容與最高品質；低於 `100%` 時會在瀏覽器本機將頁面重繪為 JPEG，以降低檔案大小。
- 壓縮流程同樣完全在本機瀏覽器完成，不會上傳文件。

### 10. ✍️ 電子簽章手寫優化

- **操作方式**：點擊頂部工具列（或手機底部懸浮列）的「**簽章**」按鈕。
- **畫筆屬性調整**：支援選擇「黑、藍、紅」三種筆跡顏色，以及「細 (2px)」、「中 (4px)」、「粗 (6px)」三種筆劃粗細。
- **防擦除邏輯**：切換顏色或粗細時，絕對不會清空已書寫的內容。
- **上傳圖片簽名**：可直接上傳現有簽名圖片做為簽章使用。

### 11. 🎛️ 快速圖章與動態產生器

- 提供 6 款常見的實用合約／簽核圖章：
  1. **樣本 (Sample)**
  2. **要保人 (簽名)**
  3. **被保險人 (簽名)**
  4. **小孩 (簽名)**
  5. **勾勾**（提供四種不同的打勾樣式）
  6. **請勿列印使用本範例文件！**
- 支援底色快速切換：**透明（預設）、紅色、藍色、黑色、黃色**。
- 圖章採用動態 Canvas 實時渲染，導出高解析度透明 PNG，邊框與字體皆經精細化排版。

### 12. 🖼️ 底圖透明貼紙張貼與複製

- **全部張貼**：一鍵將當前頁面的貼圖複製到其餘所有頁面的相同相對位置。
- **指定頁面張貼**：開啟含縮圖預覽的頁面選擇器，可複選特定頁面進行批次張貼。

### 13. 🎛️ 進階雙擊操作與齒輪設定

為解決貼紙縮得很小時控制按鈕重疊易誤觸的問題，提供全新的**操作模式設定**（置於頂部工具列齒輪按鈕內）：
- **懸浮顯示控制按鈕（預設）**：Hover 貼紙時，於四角顯示「複製」、「指定」、「刪除」以及「等比例縮放」按鈕。
- **雙擊貼圖彈窗詢問**：貼圖表面保持乾淨，透過雙擊（Double Click / Double Tap）彈出大按鈕選單（全部頁面張貼、指定頁面張貼、刪除），對小尺寸貼圖與手機操作非常友善。

### 14. 📱 手持裝置觸控事件優化

- **觸控拖曳與縮放**：直接使用手指觸碰縮圖上的簽名即可拖曳；拉動右下角縮放手柄進行等比例縮放。
- **網格防滾動干擾**：拖曳或縮放簽章時，系統自動攔截並暫停背景頁面的滾動。

### 15. 📱 手機端專屬懸浮操作列（響應式 UI）

- **自動分流**：螢幕寬度小於 768px 時，頂部 Header 自動隱藏複雜控制項。
- **拇指熱區**：載入 PDF 後，頁面底部浮現磨砂玻璃質感懸浮控制列，提供「全選/清空」、「旋轉 90°」、「刪除」、「插入頁面」與「簽章」快捷按鈕。

### 16. ↩️ 撤銷與重做（Undo / Redo）

- 完整記錄所有頁面操作（旋轉、刪除、排序、插入頁面、裁切等）與貼圖狀態。
- 支援最大 30 次歷史快照。
- **防抖快照機制**：貼紙拖曳或縮放時，於「按下瞬間」立即記錄，避免移動時產生大量冗餘快照。
- 頂部欄設有撤銷與重做按鈕，手機與電腦版皆可使用。

### 17. 📤 原生 Web Share 分享

不經過任何雲端伺服器，直接呼叫作業系統（iOS / Android / macOS / Windows）的原生分享視窗，透過 AirDrop、LINE、Email 等本地管道發送產出的 PDF。

### 18. 📲 PWA 檔案分享接收器（Web Share Target API）

- 將本 PWA「新增至主畫面」後，在其他 App 選擇「分享 PDF → Local PDF」，系統即自動開啟本程式並載入該 PDF。
- 技術上透過 Service Worker 攔截系統 POST 分享請求，暫存至瀏覽器快取後重導向至首頁自動載入。

### 19. 🌓 深色／淺色模式

支援精美的科技感深色模式與簡約淺色模式，並自動跟隨系統偏好設定。

## 🚀 本地開發與運行指南

### 1. 安裝 pnpm

本專案嚴格使用 `pnpm` 套件管理器。如果您尚未安裝，請執行：

```bash
npm install -g pnpm
```

### 2. 安裝依賴項

在專案根目錄下執行：

```bash
pnpm install
```

### 3. 啟動開發伺服器

```bash
pnpm dev
```

啟動後，在瀏覽器中開啟 [http://localhost:3000](http://localhost:3000) 即可使用。

### 4. 本地打包編譯

進行靜態網頁導出驗證：

```bash
pnpm build
```

Next.js 會將整個專案編譯並導出，生成於根目錄下的 `./out/` 資料夾中。

## 📦 雲端靜態託管部署

### A. 使用 GitHub Pages 自動部署（已設定完成）

本專案已配置 GitHub Actions 部署工作流。您只需：

1. 將程式碼推送到 GitHub 的 `main` 或 `master` 分支。
2. 前往 GitHub 倉庫的 **Settings** → **Pages**。
3. 將 **Build and deployment** 下方的 **Source** 更改為 **`GitHub Actions`**。
4. 推送後，GitHub 系統將自動在雲端完成 `pnpm install` 與編譯，並自動部署上線。

### B. 部署於 Vercel / Cloudflare Pages

1. 將專案推送到 GitHub。
2. 在 Vercel 或 Cloudflare Pages 直接匯入此倉庫。
3. 平台會自動識別 Next.js 專案並在雲端一鍵完成部署。
